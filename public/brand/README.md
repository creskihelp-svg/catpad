# Brand assets

Drop the real brand exports here using these exact filenames — the app references
them by path, so replacing a file is all that is needed.

| File | Used for | Recommended |
| --- | --- | --- |
| `logo.svg` | Navigation brand mark (includes the wordmark) | SVG, ~220×48 |
| `coin.png` | Floating hero coin, coin image fallback | Square PNG with transparent background, 512×512 |
| `hero.mp4` | Full-width hero background video | H.264 MP4, muted-friendly, 1920×1080, < 6 MB |
| `hero-poster.png` | Hero poster / fallback frame while the video loads | 1600×900 |
| `../favicon.svg` | Browser favicon | SVG, 64×64 |
| `../og.png` | OpenGraph / X share card | PNG or JPG, 1200×630 |

The files currently in this folder are flat, gradient-free placeholders generated by
`scripts/generate-brand-assets.py`. Overwrite them (or delete the script output and
commit your own exports) before going live.

The social handle in the footer and meta tags is configured with `VITE_X_HANDLE`.
